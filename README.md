A simple cli app for computing employee payroll based on employee type, timekeeping, leave usage, and loan deductions.

## Requirements
- Java 21
- Maven 3.x

## Running the project
```bash
# clone the project
git clone https://github.com/jrsm-dev/Payroll-System
cd Payroll-System

# compile
mvn compile

# run with:
mvn -q exec:java
# or
java -cp target/classes org.nud.payroll.PayrollSystem
```
