A simple cli app for computing employee payroll based on employee type, timekeeping, leave usage, and loan deductions.

## Requirements
- Java 21
- Maven 3.x

## Run
```bash
git clone https://github.com/jrsm-dev/Payroll-System.git
cd Payroll-System
mvn compile
mvn exec:java -Dexec.mainClass="org.nud.payroll.PayrollSystem"
```
